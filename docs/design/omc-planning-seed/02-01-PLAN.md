Introduce the runtime adapter boundary and attempt-outcome ingestion layer so OMC can reliably understand when an autonomous attempt ended and what it reported.

Output: runtime adapter seam, Codex adapter implementation, normalized attempt outcome parser, and durable attempt/runtime updates driven by session signals.
</objective>
